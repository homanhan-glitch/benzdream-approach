파일의 SHA256으로 동일 원본을 건너뛴다. 같은 기준일의 변경 원본, 날짜 역전, 비공개 상태와 공개 ledger 불일치는 자동 재작성하지 않고 중단한다. `no_new_source`는 배포할 변경이 없는 상태다. 새 날짜가 없어도 미배포된 생성물이 있으면 Git 상태와 마지막 배포 상태를 확인한다.

## 출처와 필터

- `Sheet1`: 유효성, 회사 범위, 열 이름, 커미션번호 결측·중복·형식을 검사한다. 숫자 10자리의 선행 0과 DKR 접두사를 보존한다. 과거 9자리 번호로 강제 변환하거나 새 회사와 과거 회사를 직접 차분하지 않는다.
- `Stock Balance Report`: Date로 파일명 MMDD와 연도를 검증하고 회사가 HS HYOSUNG인지 확인한다. 차량 행이 Sheet1과 중복되는지 검사하며 재고에 더하지 않는다.
- 고객 및 내부 판매가능 재고: 입고 물량, 미배정, 차량 상태 판매 가능, 가용 여부 판매 가능, 배정 전시장 Mercedes Benz Korea. 전시·MPC 위탁·Virtual VIN·Pre-Order VIN 제외. 데이터 검증 오류, 유형 누락, 상태 충돌, 차종·연식·색상 결측은 격리한다.
- 자율 배정 제한과 실제 출고 여부는 별도 확인이 필요하다. 공개 화면은 대수를 표시하지 않고 색상 조합을 보여준다. PDD 과거 날짜를 즉시출고 확정으로 표시하지 않는다.
- 실제 모델 연도별·차종별·외장/내장 조합 전체를 재구성한다. 신규 커미션도 포함한다. 원문에 없는 색상이나 연식을 추측하지 않는다.

## 계약 추정 정의

**전국 순계약 추정 = 효성 입고 차량의 관측 신규 계약 전환 − 계약 해제 + 전국 판매가능 재고의 원본 이탈 − 이탈 차량 재등장.**

효성 계약은 전국 확정 계약이 아니다. 다른 회사 계약은 원본에 직접 노출되지 않으므로 전국 이탈분은 추정이며, 조회범위 변경·정정·이관도 포함될 수 있다. 일·주·월 합계는 파일 관측일 기준이고 정확한 계약일이 아니다. 기간 합계를 고유 차량 판매대수로 표시하지 않는다.

처음부터 계약 상태인 신규 관측 차량, 예정→입고 전환, 회사 범위 변경은 신규 계약으로 세지 않는다. 별도 수지 조정 항목으로 검증한다. 계약→미계약→계약이면 +1/−1/+1이고 누계는 +1이다. 전국 이탈 차량은 재등장 때 한 번 차감한다. 원본에 남아 있으면서 판매 대상에서 제외된 차량을 원본 이탈로 세지 않는다. 가상·예정 차량이 대량 삭제되어도 계약으로 합산하지 않는다.

주간/월간 차트는 달력 구간, 최근 1주/1개월 분석은 최근 7일/30일 내 관측 구간이다. 새 기준선 이전은 0 실적이라고 가정하지 않는다. 이전 이력 선택 메뉴는 원래 계산 정의·값을 보존한다.

## 배포 검증

커미션 결측·중복 0, 재고 수지(이전+편입−이탈=현재), 계약 범위 수지, 전체 차종·연식·외장·내장 조합 커버리지와 총합을 검사한다. 기존 ledger와 상태 및 기존 웹 보관본의 SHA256을 보존한다. 새 파일 내 개인고객·UCID·차대번호·엔진번호·계약 원문·인센티브 자료는 공개 JSON/기록에 넣지 않는다.

새 양식의 큰 행 증감, 격리 행, 범위 편입은 검증 보고서의 수치로 보고한다. 운영 페이지 갱신과 자동화 상태 기록을 별도 검증한다.
